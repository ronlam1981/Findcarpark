# 分區參考資料

`dspu-18-districts-official.jpg` 係用戶提供嘅官方《澳門總體規劃》「十八分區」
圖表（規劃分區 → 統計分區/新填海區對照表），`index.html` 入面 `ZONE_KEYWORDS`
呢個表就係跟返呢份官方文件砌嘅。

如果日後要調整地區分類，或者發現邊個停車場分錯咗地段，睇返呢張圖可以
確認正確嘅官方分區名，再去 `index.html` 搵 `ZONE_KEYWORDS` 加／改關鍵字。

留意：呢張圖界定咗**分區叫咩名、分幾多個**（官方、可信），但**邊條街屬
邊個分區**（`ZONE_KEYWORDS` 入面嘅關鍵字）仍然係憑一般認知砌，未對住
data.gov.mo 嘅真實停車場地址逐個核實過。
